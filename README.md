# NIKKE // OVERLOAD ARCHIVE

보유 니케와 오버로드 추천 옵션을 한곳에서 관리하는 비공식 팬 아카이브입니다.

## 주요 기능

- 2026-08-12 기준 플레이어블 니케 196명 수록
- 한글·영문 이름 검색 및 제조사·클래스·무기 필터
- 카드 클릭으로 미보유 흑백 → 보유 컬러 전환
- 보유 목록을 브라우저에 자동 저장
- 머리·몸통·팔·다리, 각 3개씩 총 12개 오버로드 목표 표시
- GitHub Pages 자동 배포

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm ci
npm run dev
```

프로덕션 정적 빌드는 `npm run build`로 생성되며 결과물은 `dist/client/` 폴더에 저장됩니다.

## 데이터와 권리

캐릭터 명단·한국어 이름·대표 이미지는 NIKKE International Wiki의 CC BY-SA 데이터를 바탕으로 2026-08-12에 스냅샷했습니다. 오버로드 값은 범용 PvE 원칙과 캐릭터 기믹을 바탕으로 작성한 1차 목표이며, 파티·콘텐츠·큐브와 수치 임계에 따라 달라질 수 있습니다.

이 프로젝트는 비공식·비상업 팬 프로젝트입니다. GODDESS OF VICTORY: NIKKE 및 캐릭터의 권리는 SHIFT UP에 있습니다.

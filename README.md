# NIKKE // OVERLOAD ARCHIVE

보유 니케와 오버로드·하모니 큐브 추천을 한곳에서 관리하는 비공식 팬 아카이브입니다.

## 주요 기능

- 2026-10-23 기준 수집 가능한 플레이어블 니케 203명 수록
- 203명 전원의 일러스트와 아이콘 폴백
- 한글·영문 이름 검색 및 제조사·클래스·무기 필터
- 카드 클릭으로 미보유 흑백 → 보유 컬러 전환
- 보유 목록을 브라우저에 자동 저장
- 머리·몸통·팔·다리, 각 3개씩 총 12개 오버로드 목표 표시
- 17종 하모니 큐브를 기준으로 203명 전원의 1순위·해당하는 대안 큐브 표시
- 네 종류 이상의 오버로드 목표도 4부위 × 3줄에 빠짐없이 배치
- 검토한 추천의 출처 링크, 개별 검토 날짜, 범용 추천의 한계 표시
- GitHub Pages 자동 배포

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm ci
npm run dev
```

프로덕션 정적 빌드는 `npm run build`로 생성되며 결과물은 `dist/client/` 폴더에 저장됩니다.

## 품질·보안 검사

```bash
npm run qa
npm run security:audit
npm run artwork:check
```

`qa`는 타입, 린트, 정적 빌드, 데이터 완전성·보유 ID 보존·옵션 배치·의존성 버전 일치·배포 자산·이미지 검사기 테스트를 실행합니다. 빌드 결과에는 해시 기반 Content Security Policy가 자동 적용됩니다. 주간 및 명단·검사기 변경 PR의 GitHub Actions는 전신 일러스트와 대체 아이콘을 모두 검사하고, HEAD 실패는 GET으로 재확인하며, 실제로 없어진 파일은 실패로 보고합니다.

`security:audit`는 개발 도구를 포함한 전체 의존성을 검사하고 낮음 이상의 알려진 취약점이 있으면 실패합니다. PR 검사와 배포 빌드 모두 이 검사를 실행합니다. 보안 의존성 변경의 근거와 호환 계층 유지 범위는 [보안 수정 기록](docs/security-update-2026-10-23.md)에 있습니다.

## 2026-10-23 갱신

- 정식 출시된 길티 : 마이티 바니, 신 : 스위프트 바니, 벨로타 : 펌킨 위치를 추가했습니다. 위키의 208개 플레이어블 항목 중 영구 영입할 수 없는 임시 플레이 전용 5명은 보유 명단에서 제외합니다. [명단·공식 출시 근거](docs/roster-update-2026-10-23.md)
- 디젤 전신 이미지를 현재 위키 파일 `Diesel_FB.png` 주소로 교체했습니다. 기존 200명의 보유 ID는 유지합니다.
- 신규 3명의 오버로드·큐브와 기존 캐릭터의 누락 개별 추천을 보완했습니다. 이번에 검토한 오버로드 5명·큐브 8명만 검토 날짜와 출처를 갱신했습니다. [추천 근거와 해석 범위](docs/build-data-update-2026-10-23.md)
- 범용 오버로드 116명·큐브 106명은 개별 스킬 검증 전 안내를 표시합니다. 모든 추천을 최신 개별 공략으로 재검증했다는 의미는 아닙니다.
- React·React DOM·React Server Components를 19.3.1로 함께 정렬하고, Dependabot에서 연동 패키지를 다른 그룹에 섞지 않도록 명시했습니다.

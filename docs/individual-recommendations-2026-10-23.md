# 2026-10-23 개별 추천 후속 검토

이 문서는 같은 날의 [초기 데이터 보완](build-data-update-2026-10-23.md)에 이어, 남은 무기별 범용안과 출처 기록이 없던 개별 추천을 검토한 기록입니다.

최종 데이터는 203명 모두 OL·큐브 출처가 있습니다. 이번에 OL 199명·큐브 196명의 자료를 새로 반영했고, 기존에 검토한 나머지 추천은 보존했습니다. OL은 목표 배치 132명·목표 미지정 71명이며, 큐브 203명 중 별도 PvP 후보를 확인한 191명에 해당 목록을 추가했습니다.

## 검토 기준

- Prydwen의 캐릭터별 **Gear Investment**, **Cube Investment**, 관련 스킬·운용 설명을 조회했습니다. 기존에 Nikke.gg의 개별 분석으로 확인한 추천은 해당 근거를 유지합니다.
- `verifiedAt`와 원본의 `checkedAt`는 이 아카이브에서 자료를 확인한 날짜입니다. 공략의 작성일·최종 수정일이나 실제 게임 내 실측일이 아닙니다. 모든 원문이 최근에 작성되었다고 주장하지 않습니다.
- 표의 옵션과 원문의 장탄·차지 속도·재장전 조건을 함께 읽습니다. 본문과 투자 표가 다르면 조건과 판단 범위를 설명하며, 기계적으로 무기별 기본안을 붙이지 않습니다.
- 기본형과 애장품형의 추천을 합치지 않습니다. 기본형을 기준으로 기록한 캐릭터는 설명에서 그 범위를 밝힙니다.
- 직접 전투 시뮬레이션이나 사용자 계정의 피해량 측정은 하지 않았습니다. 팀 버프, 큐브 레벨, 옵션 수치에 따른 최종 조정은 필요합니다.

## 데이터 표현

| 상태 | 의미 | 화면 |
| --- | --- | --- |
| `reviewed` | 개별 공략에서 구체적인 추천을 확인 | 목표 배치 또는 추천 큐브 표시 |
| `no-target` | OL 표가 비어 있거나 조건 차이로 단일 목표를 확정하지 않음 | 빈 목표 배열, 재설정 비추천과 개별 투자 조건·선택지 |
| `unavailable` | 확인한 자료에 개별 추천 근거가 없음 | 목표 배치·큐브 1순위를 만들지 않고 근거 부족 표시 |

목표가 없는 캐릭터에 공격력·장탄 수 등의 1줄 목표를 임의로 넣지 않습니다. `no-target`은 그 캐릭터에게 어떤 옵션도 효과가 없다는 뜻이 아닙니다. 장비 레벨을 올려 얻는 기본 능력치와 옵션 재설정의 투자 효율도 구분합니다.

공략의 범위형 줄 수는 12칸 안에서 가능한 배치 예시로 표현하며 원래 범위와 조건을 설명에 남깁니다. 선택적인 유효 옵션은 핵심 목표와 구별합니다. PvP 큐브는 별도 후보 목록으로 표시하며 PvE 순위를 그대로 적용하지 않습니다.

## 유지보수

검토 원본은 `scripts/reviews/shard-a.json`, `shard-b.json`, `shard-c.json`, `follow-up.json`입니다. 각 레코드에 캐릭터명, 확인일, 출처와 OL·큐브의 개별 판단을 기록합니다. `scripts/reviewed-recommendations.mjs`가 이름 중복, 근거 누락, 날짜, 상태와 목표의 모순을 검사하고 기존 생성기의 결과 위에 적용합니다. 검토 원본이 없는 부분은 기존 데이터를 유지하며 빌드 실행만으로 확인일을 바꾸지 않습니다.

벨로타 : 펌킨 위치는 초기 보완의 기믹 기반 차지 속도 1줄 대신, 추가로 확인한 Prydwen 개별 공략의 속사·버스트 수급용 장탄 1~2줄로 수정했습니다. PvP 차지 속도는 기본 목표에서 분리했습니다.

`app/overloads.json`과 `app/cubes.json`은 생성 결과입니다. 추천 수정은 출처를 다시 확인한 뒤 검토 원본에서 하고 두 생성기를 실행합니다. 한 섹션만 검토한 경우 다른 섹션의 출처와 확인일을 덮어쓰지 않습니다.

회귀 검사는 도로시의 마지막 탄환 기믹, 아드미·볼륨·기본 프리바티의 목표 미지정, 자료와 생성 결과 일치, 잘못된 출처·검토 상태 거부, 12칸 배치와 PvP 큐브 식별자를 확인합니다. 배포 전 전체 `npm run qa`와 `npm run security:audit`를 실행합니다.

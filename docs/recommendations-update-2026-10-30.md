# 추천 자료 재검토 — 2026-10-30

> 후속 검토에서 라푼젤의 다른 개별 공략과 신규 Bezel 큐브를 확인했습니다. 아래 내용은 최초 검토 기록이며, 현재 반영 사항은 [후속 검토](sanctuary-cube-followup-2026-10-30.md)를 확인해 주세요.

검토일은 공개 자료를 조회하고 대조한 날짜입니다. 공략 발행일이나 실제 전투 시험일이 아니며, 기존 전체 니케를 다시 검증했다는 뜻도 아닙니다.

## 반영 범위

`scripts/reviews/follow-up.json`에 아래 4명의 개별 검토를 추가했습니다. 기존 생성기의 범용/초기 추천보다 이 출처 검토를 우선 적용하는 기존 로더를 사용합니다. 벨로타를 포함한 나머지 검토일은 보존합니다.

| 대상 | 반영 내용 | 근거 상태 |
| --- | --- | --- |
| 길티 : 마이티 바니 | 우월 4·공격 4·장탄 1~2줄의 하한을 표시하고, 차지 속도 고정 줄 수와 차지 대미지 일괄 금지를 제거했습니다. | Prydwen 개별 투자 표·본문 확인 |

바니 두 명의 큐브는 **Engage 전투 모드**에서 크러쉬를 우선 비교합니다. Engage는 큐브 이름이 아닙니다. Stance 모드, 큐브 육성 차이, 장탄 확보량, 파츠 공격 비중에 따라 대안을 고르는 조건을 함께 적었습니다. 이번 대조로 기존 자료와의 불일치를 확인했지만, 해당 공략이 정확히 언제 바뀌었는지는 확인하지 못했습니다.

- [nikke.gg 2026년 10월 티어 변경 설명](https://nikke.gg/october-2026-tier-list-changes/)도 확인했습니다. 개별 캐릭터의 상대평가 변경만으로 기존 5인 조합의 유효성이나 승률이 검증되지는 않습니다. 확인한 신규 페이지에는 순서와 조건을 검증할 수 있는 완성된 PvP 편성이 없으므로 아레나 30개 조합과 검토일 2026-10-27은 유지했습니다.

## 검증

- 실제 205명 roster를 입력한 `loadReviews` 검증 통과: 출처 검토 203건을 읽었고, 이번 4건의 이름·출처·날짜·상태가 유효합니다. 나머지 2명은 기존 생성기에 직접 기록된 개별 출처 추천을 유지합니다.
- 신규 4건의 소스 내용, 목표 합계와 선택지 분리, 미공개 추천의 빈 값, 기존 벨로타 기록 보존을 별도 단발 검증했습니다.
- 생성 후 `app/overloads.json`과 `app/cubes.json`은 각각 205건입니다. 이전 배포와 객체 단위로 비교하여 위 4명 외의 추천과 확인일이 바뀌지 않았음을 확인했습니다.
- 통합 `npm run qa`의 빌드·타입·린트 및 정적 테스트 87개, `npm run test:browser`의 격리된 headless Chrome 검사 7개가 모두 통과했습니다. 실패·생략은 0입니다. 신규 캐릭터 검색·보유 저장·상세 표시와 아레나 추천 회귀를 포함합니다.
- 추천 근거가 없는 캐릭터의 투자 우선도는 화면에 `판단 보류`로 표시합니다. 기존 내부 `skip` 값이 근거 없는 재설정 비추천 판단으로 보이지 않도록 구분했습니다.

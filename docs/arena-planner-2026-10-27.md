# 보유 기반 스페셜 아레나 추천

2026-10-27에 공개 전문 공략을 확인하여 완성된 5인 편성 30개를 수록했습니다. 최신 개별 캐릭터 페이지와 기존 공개 조합을 함께 사용하며, 확인 날짜를 공략의 작성일이나 최신 메타 순위로 해석하지 않습니다. 각 조합의 근거는 `app/arena-presets.json`의 출처 링크에서 확인할 수 있습니다.

## 사용 방법

1. 기존 니케 카드에서 보유 캐릭터를 등록합니다.
2. 상단의 **보유 기반 아레나 덱**으로 이동합니다.
3. 해당하는 캐릭터의 애장품이 최종 단계라면 별도로 체크합니다.
4. 편성 화면의 왼쪽부터 P1~P5 순서로 배치합니다. 첫 버스트 담당자와 투자·공격력·상대 조건도 확인합니다.

보유 목록은 기존 저장 형식을 유지하고, 애장품 확인 상태는 별도의 브라우저 저장 키 `nikke-overload-archive:arena:v1`을 사용합니다. 서버나 외부 계정으로 보유 정보를 보내지 않습니다.

## 추천 범위

- 보유 및 애장품 조건을 충족하는 완성 조합만 선택합니다. 부족한 캐릭터를 실제 추천 덱에 채워 넣지 않습니다.
- 최대 3개 덱을 만들며, 전체 덱에서 동일 캐릭터를 재사용하지 않습니다. 일반형과 애장품형도 같은 캐릭터 ID를 사용합니다.
- 가능한 덱 수를 우선하고, 같은 수의 묶음에서는 자료에 설정한 편집 우선순위 합을 비교합니다. 우선순위는 승률이나 측정된 전투 성능이 아닙니다.
- 완성되지 않는 후보는 미보유 캐릭터·미확인 애장품·현재 추천과의 중복을 나눠 표시합니다. 목록에 없는 임의 조합은 생성하지 않습니다.
- 애장품은 최종 단계 완료를 기준으로 보수적으로 필터링합니다. 일부 공략의 최소 요구 단계보다 높게 요구할 수 있습니다.
- 첫 버스트 경로는 전원 생존·행동 가능 상태를 기준으로 합니다. 사망, 기절, 상대 스킬, 큐브, 장비와 스킬 투자에 따라 실제 진행은 달라집니다.
- 상대 덱과 전투력을 입력받지 않으므로 맞춤 카운터·승률·정확한 버스트 속도를 계산하지 않습니다. 공격용/방어용 조건은 각 팀 설명에 표시합니다.

Prydwen의 라플라스: 얼티메이트 히어로 팀 479·480·487·488 및 에밀리아 팀 149·150은 실제 팀 카드의 캐릭터 순서와 애장품 표시까지 확인했습니다. nikke.gg의 기존 SP 공략은 2023-11-29 작성본임을 출처 제목에 명시했습니다.

프리셋을 추가할 때는 다섯 명의 정확한 roster 이름, 편성 순서, 첫 자동 버스트 경로, 애장품 조건, 투자 조건, 약점, 실제 확인한 출처를 함께 기록합니다. 캐릭터 한 명만 비슷한 역할로 임의 치환하지 않습니다. 현 목록은 재진입형과 다단계 버스트를 제외하고, 아니스: 스타는 단독 B1인 편성만 사용합니다. 이러한 조건을 바꾸려면 자동 버스트 검증 규칙도 함께 확장해야 합니다.

`tests/arena-planner.test.mjs`는 실제 데이터 참조·자동 버스트 순서, 보유 제한, 다섯 명 고유성, 덱 간 중복, 애장품 조건, 부족한 명단, 탐욕적 선택의 실패 사례 및 입력 보존을 검사합니다. `npm run qa`에 포함됩니다.

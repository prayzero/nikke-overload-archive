# 라푼젤 : 생츄어리·Bezel 큐브 후속 검토

자료 확인일: 2026-10-30. 실제 전투 실험이나 확정 최적 세팅을 의미하지 않습니다. 이번 검토는 라푼젤 : 생츄어리 1명과 새 큐브 1종에 한정되며 기존 니케의 확인 날짜를 일괄 갱신하지 않습니다.

## 라푼젤 : 생츄어리

- [GameWith 개별 가이드](https://gamewith.jp/nikke/article/show/584270)의 OL 표는 차지 속도·우월 코드·최대 장탄 수·차지 대미지를 제시합니다. 줄 수는 없으며 나열 순서를 확정 효율 순위로 해석하지 않습니다. `no-target` 상태에서 후보만 표시하고 4부위 배치는 만들지 않습니다.
- 같은 가이드는 차지 속도로 풀 차지 공격과 회복 빈도를 높이는 부스트, 최대 HP의 비거, 재장전의 베어를 제안합니다. [NikkeHub 개별 페이지](https://nikkehub.com/nikkes/rapunzel-sanctuary)는 공용 버퍼 조합·풀투자 가정에서 베어를 추천합니다. 화면은 베어를 기본 후보, 부스트·비거를 대안으로 표시하고 출처별 우선 후보가 다름을 설명합니다. 확정된 효율 순위나 PvP 추천으로 제시하지 않습니다.
- GameWith의 스킬 문구에서 차지 속도 증가·감소 면역은 **풀 차지 상태일 때**에 한정됩니다. 기존 설명이 전투 내내 차지 속도가 무효라는 뜻으로 읽히지 않도록 수정했습니다.
- [Prydwen](https://www.prydwen.gg/nikke/characters/rapunzel-sanctuary)의 투자 가이드는 여전히 비어 있습니다. GameWith는 출시 초기 스펙 기반 평가이며 NikkeHub도 출시 초기 변동 가능성을 알립니다. 모든 신규 추천에 `PvE (출시 초기 참고안)`을 표시합니다.
- [Game8](https://game8.jp/nikke/838997)에도 장비 표가 있으나 본문의 스킬 제목 불일치·버스트 설명 공백 등으로 줄 수를 독립 확정할 근거가 부족했습니다. 해당 페이지의 줄 수나 수치 시뮬레이션은 반영하지 않습니다.

기존 검토 문서의 ‘추천 보류’는 당시 Prydwen 중심의 조사 상태입니다. 이번에 확인한 다른 개별 공략으로 후보를 보완했지만 목표 줄 수·전투별 최적값은 여전히 미확정입니다.

## Bezel Cube

기존 17종에 **Bezel 큐브** 1종을 추가해 카탈로그는 18종입니다. 한국어 정식 표기를 확인하지 못해 영문 이름을 사용합니다.

| 조건 | 확인 내용 |
| --- | --- |
| 발동 | 풀 버스트 진입 시 |
| 대상·효과 | 자신에게 최대 HP 증가, 현재 HP 회복 없음 |
| 중첩 | 최대 3중첩 |
| Lv. 1 / 3 / 7부터 | 1중첩당 4.01% / 6.01% / 8.02% |
| 획득처 | 로스트 섹터 30 |

- [공식 업데이트 공지](https://nikke.hotcool.tw/News_detail-237) 12.5항은 신규 하모니 큐브 추가를 알립니다.
- [GameWith 큐브 표](https://gamewith.jp/nikke/article/show/373305)의 실제 HTTP HTML에서 일본어 이름 `レリックベゼルキューブ`, 레벨 1의 4.01%, 3중첩, 획득처를 확인했습니다. 검색 도구에 남은 이전 캐시에는 신규 표가 없어 실제 응답과 구분했습니다.
- [NIKKE Wiki 고정 수정본 72626](https://nikke-goddess-of-victory-international.fandom.com/wiki/Lost_Sector/Harmony_Cubes?oldid=72626), 수정 시각 `2026-10-30T02:34:33Z`의 API 원문에서 발동·HP 회복 제외·레벨별 수치·최대 중첩을 확인했습니다.
- 확보한 원문에 없는 지속 시간과 중첩 합산 방식은 단정하지 않습니다. 3중첩 합계나 영구 지속 수치도 계산해 제시하지 않습니다.
- 라푼젤의 개별 추천에 Bezel이 없어 새 큐브를 자동 배정하지 않습니다. 페이지의 ‘새 큐브 정보’ 링크로 효과·레벨·획득처·확인일·출처를 볼 수 있습니다.

## 검증 범위

추천 생성 후 라푼젤 외 204명의 OL·큐브 레코드가 기존과 같은지 비교합니다. 회귀 검사는 후보와 미지정 줄 수의 구분, 조건부 차지 면역 설명, 출처 허용 목록의 우회 차단, Bezel 수치·출처의 정적 출력, 실제 상세 창·보유 저장·아레나 추천, 320px 화면의 가로 넘침을 포함합니다. 사용자 프로필을 사용하지 않는 격리된 헤드리스 검사로 실행합니다.

로컬 검증 결과: `npm run qa`의 빌드·타입·린트 및 정적 테스트 **88/88**, `npm run test:browser`의 **8/8** 통과, 전체 의존성 보안 감사 **0건**입니다. 데스크톱·320px Bezel 안내 캡처도 확인했습니다. 제한 환경의 첫 빌드는 HTML 생성 누락으로 실패했으며 같은 소스를 일반 실행 권한으로 검사한 최종 결과입니다. 변경 전후 JSON 비교에서 라푼젤만 바뀌었고 나머지 204명은 동일했습니다.

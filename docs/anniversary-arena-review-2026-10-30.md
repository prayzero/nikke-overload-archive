# 4주년 신규 니케 아레나 편성 검토

확인일: **2026-10-30**. 마리안 : 퀸과 라푼젤 : 생츄어리를 조사했으나 두 캐릭터가 포함된 아레나용 5인 구성·P1~P5·운용 조건을 확인할 근거는 확보하지 못했습니다. **신규 추천 덱은 추가하지 않았습니다.** 공개되지 않았거나 검색에 잡히지 않는 모든 공략의 부재를 뜻하지는 않습니다.

## 실제 반영

보유한 두 니케를 아레나 화면의 ‘보유 니케의 편성 검토’에 표시합니다. 확인된 역할·조건, 제외 이유, 출처와 확인일을 제공하며 장비 상세로 이동할 수 있습니다. 미보유인 캐릭터는 이 영역에 나오지 않습니다. 보유 해제·재접속도 기존 저장 목록과 연동됩니다.

기존 검토된 30개 조합의 명단·자리·버스트·우선순위·조건과 2026-10-27 확인일은 그대로 유지합니다. 신규 검토의 2026-10-30 날짜는 해당 기록에만 붙입니다. 대기 니케는 추천팀 수·대안·편성 복사에 포함하지 않으며, 검토 대기 니케를 프리셋에 넣으면 데이터 검사와 추천 엔진에서 오류로 거부합니다. 보유 캐릭터 총수에는 정상 포함합니다.

이는 실제 아레나 신규 덱 추가 완료가 아니라 **확인 가능한 조사 결과를 추천 시스템에 반영한 업데이트**입니다. 두 캐릭터의 완성 조합을 추천하는 부분은 근거 확보 전까지 남아 있습니다.

## 마리안 : 퀸

- [Prydwen 개별 페이지](https://www.prydwen.gg/nikke/characters/marian-queen): B3·MG와 전체 공격 버스트를 확인했습니다. 팀 가이드는 미공개입니다. 페이지의 일반적인 오래된 리뷰 안내 문구를 실제 출시 후 성능 평가로 해석하지 않습니다.
- [nikke.gg 10월 28일 초기 분석](https://nikke.gg/marian-queen-early-analysis/): 검색 본문의 PvP 절은 시험 대기입니다. 일반 팀 제안에는 11월 5일 출시 예정인 홍련 : 신살이 포함돼 있고, 표의 브리드와 설명의 크라운이 일치하지 않아 신규 아레나 편성으로 채택하지 않았습니다. 직접 본문/공개 page-data 접근 중 일부는 403 응답이었으며 접근 성공으로 기록하지 않습니다.
- [GameWith](https://gamewith.jp/nikke/article/show/584272): 아니스 : 스타 / 크라운 / 마리안 : 퀸 / 라피 : 레드 후드 / 마스트 : 로망틱 메이드의 표는 풍압 적을 상대하는 작열 MG 편성입니다. 아레나 배치의 근거로 사용하지 않습니다.
- [니케허브](https://nikkehub.com/nikkes/marian-queen)의 파트너 역할, [Game8](https://game8.jp/nikke/838996)의 불완전한 편성 표도 확인했으나 완성된 PvP 조합을 검증할 수 없었습니다.
- [게임톡의 사용처 분석](https://www.gametoc.co.kr/news/articleView.html?idxno=112578)은 PvP 가능성과 낮은 버스트 수급을 함께 설명하며 추가 연구가 필요하다고 합니다. 실제 5인 아레나 팀은 제시하지 않습니다.

## 라푼젤 : 생츄어리

- [Prydwen 개별 페이지](https://www.prydwen.gg/nikke/characters/rapunzel-sanctuary): B2·RL 지원형입니다. 버스트 시 전투 불능 아군이 3명 이상이어야 전투당 1회 부활하며, 이후 자신의 버스트 쿨다운이 40초 증가합니다. 전원 생존 첫 버스트에서는 부활 분기가 발동하지 않습니다. 팀 가이드는 미공개입니다.
- [GameWith](https://gamewith.jp/nikke/article/show/584270): 아니스 : 스타 / 크라운 / 마리안 : 퀸 / 스노우화이트 : 헤비암즈 / 생츄어리의 표는 잡몹·보스를 상대하는 범용 PvE 설명입니다. 추가 B2 권장은 부활 이후 쿨다운 대응을 위한 조건이며, PvP 첫 버스트나 부활 성공을 보장하지 않습니다.
- [Game8](https://game8.jp/nikke/838997)의 추천 5칸은 생츄어리 외 명단이 없었고, [니케허브](https://nikkehub.com/nikkes/rapunzel-sanctuary)는 출시 초기 경고와 미작성 가이드를 표시했습니다.
- 기존 B1 라푼젤·퓨어 그레이스와 이름/버스트를 구분합니다. 차지 속도 면역은 풀 차지 상태 조건이 있어, 차지 속도 투자와 무조건 모순된다고 판단하지 않습니다. 차지 유지 보호막도 자동 아레나에서 상시 적용된다고 가정하지 않습니다.

## 검색과 검증 범위

한국어·영어·일본어 및 일부 중문 검색, 전문 개별 공략과 아레나 종합 가이드, 공개 커뮤니티·영상 검색을 확인했습니다. [GameWith 아레나 종합 공략](https://gamewith.jp/nikke/article/show/379079)에 나온 최신 두 캐릭터 링크는 새 캐릭터 공통 메뉴이며 본문의 해당 5인 조합은 아닙니다. PvE 표나 검색 결과의 이름 일치만으로 아레나 근거를 만들지 않았습니다.

현 엔진은 전원 생존 시 첫 자동 버스트 대상을 검사하며, 사망 시점·실전 쿨다운·부활 이후 순환을 시뮬레이션하지 않습니다. 신규 조합을 확정할 때에는 실전 자동 버스트와 자리·상대·투자 조건을 검토한 뒤 해당 `pendingReviews` 항목을 제거하고 근거가 있는 프리셋을 추가해야 합니다.

회귀 검사에는 대기 정보의 정확한 보유 ID 연동, 기존 라푼젤 변형 구분, 추천팀과 복사 결과에 대기 캐릭터가 섞이지 않는지, 잘못된 날짜·근거·중복 검토 거부, 상세창 포커스 복귀와 320px 화면을 포함합니다. CUA·컴퓨터 유즈와 사용자 프로필은 사용하지 않습니다.

로컬 실행 결과: `npm run qa`의 빌드·타입·린트·정적 검사 **91/91**, 격리 헤드리스 검사 **9/9** 통과, 전체 의존성 보안 감사 **0건**입니다. 기존 30개 프리셋과 24개 출처·확인일이 동일하고, 명단·OL·큐브 JSON도 의미상 변경이 없음을 비교했습니다. 데스크톱과 320px 캡처를 확인했습니다. 이 검사는 제품의 동작 검증이며 실제 게임 대전에서 신규 조합을 시험했다는 의미가 아닙니다.
